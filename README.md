# Stretch & Thrive

คือผมจะทำแอพเกี่ยวกับ office syndrom feature มีหน้า login sign up เอาให้แอพสวยและใช้ง่าย จะมีแจ้งเตือยบอกว่าตอนนี้นั่งนานไปไหม ควนลึกไปยืดเส้น มีคลิปสอน มีนัดหมอออนไลนได้ ทพออกมาเป็น prototype คือผมจะทำแอพเกี่ยวกับ office syndrom feature มีหน้า login sign up เอาให้แอพสวยและใช้ง่าย จะมีแจ้งเตือยบอกว่าตอนนี้นั่งนานไปไหม ควนลึกไปยืดเส้น มีคลิปสอน มีนัดหมอออนไลนได้ ทพออกมาเป็น prototype Sep 30 at 2:50 PM สร้างหน้าโฟลว์แอป OfficeCheck เลือกแนวดีไซน์ที่ต้องการให้ผมสร้างครับ? Frosted clinical calm +2 more ทำเป็นต้นแบบให้แล้วครับ 4 หน้า ตามแนว "Frosted clinical calm" หน้าแรก: นาฬิกานับเวลานั่งต่อเนื่อง พร้อมการ์ดเตือน "ถึงเวลาลุกขึ้นยืดเส้น" (เลื่อนออกไป 5 นาทีได้ หรือกดเริ่มนับใหม่) คลิปสอนยืดเส้น: คอ/บ่า หลังล่าง ข้อมือ นัดหมอออนไลน์: เลือกหมอและเวลา แล้วกดยืนยัน เข้าสู่ระบบ/สมัคร และหน้าโปรไฟล์ที่ตั้งรอบการเตือนได้ (30/45/60 นาที) ตอนนี้ยังเป็นต้นแบบ ข้อมูลยังไม่ถูกบันทึกจริง — ถ้าอยากให้สมัคร/ล็อกอินและบันทึกข้อมูลได้จริง บอกได้เลยครับ Requirements Streak (points for keep user motivation) แก้ชื่อแอพ UniStretch English version ประกาศประชาสัมพันธ์ในหน้า home (health check up event) user feedback ให้รีวิวแอพ ดาวและคำแนะนำเพิ่มเติม (validation) เหมือนเติมไฟติ้กต้อก เชื่อม database ด้วย
